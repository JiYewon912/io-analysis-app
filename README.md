# 과제물1: 산업연관표분석 웹앱

2023년 산업연관표 연장표(생산자가격)를 브라우저에서 불러와 **원자료를 탐색**하고, **최종수요 증가가 경제 전체에 미치는 파급효과**를 계산하는 웹앱입니다. 서버 없이 GitHub Pages에서 동작하며, 계산은 방문자의 브라우저 안에서 Python(Pyodide)으로 실행됩니다.

## 1. 사용 방법

1. 페이지 상단 **분류 수준**을 고르고 **불러오기**를 누릅니다. (처음에는 Python 환경을 내려받느라 수십 초 걸릴 수 있습니다.)
2. **원자료 탐색**: 시트 → 행을 고르면 그 행이 각 열과 어떻게 연결되는지 표로 나옵니다. 행·열 검색창으로 산업을 찾을 수 있습니다.
3. **시뮬레이터**: 산업과 최종수요 증가액(백만원)을 입력하고 **시나리오에 추가**를 누릅니다. 여러 산업을 추가하면 합산됩니다.
4. **파급효과 계산**을 누르면 생산·수입·부가가치유발액 합계, 상위 15개 산업, 전체 산업별 결과표가 나옵니다. **CSV 다운로드**로 전체 결과를 저장할 수 있습니다.
5. 분류 수준을 바꾸려면 다른 수준을 고르고 다시 **불러오기**를 누릅니다.

## 2. 분류 수준

| 분류 수준 | 부문 수 | 데이터 파일 |
| --- | --- | --- |
| 기본부문 | 380 | `data/io-2023-basic.xlsx` |
| 소분류 | 165 | `data/io-2023-small.xlsx` |
| 중분류 | 83 | `data/io-2023-medium.xlsx` |
| 대분류 | 33 | `data/io-2023-large.xlsx` |

네 파일 모두 같은 12개 시트(총·수입·국산 거래표, 총·수입·국산 투입계수표, 생산·수입·부가가치 유발계수표, 최종수요 항목별 유발액 3종)로 구성되어 있습니다. 분류가 거칠수록 부문이 합쳐져 산업 구조를 한눈에 보기 좋고, 세밀할수록 특정 산업의 효과를 구체적으로 볼 수 있습니다.

## 3. 분석 방법

- **투입계수** `Ad`(국산), `Am`(수입): 산업 j가 1원어치를 생산할 때 투입되는 국산·수입 중간재의 비율
- **생산유발계수** `L = (I − Ad)⁻¹` (레온티에프 역행렬): 최종수요 1원 증가가 직·간접적으로 유발하는 국내 생산
- **수입유발계수** `M = Am · L`
- **부가가치유발계수** `V = diag(v) · L` (`v`: 부가가치율)
- **시뮬레이션**: 최종수요 증가 벡터 `ΔF`에 대해
  - 생산유발액 = `L · ΔF`
  - 수입유발액 = `M · ΔF`
  - 부가가치유발액 = `V · ΔF`
  - 생산승수 = 생산유발액 합계 ÷ 수요 증가액 합계
- **계수 검증**: 자료를 불러올 때 `(I − Ad)L = I`, `Am·L = M`, `v∘L = V`가 성립하는지(잔차 1e-8 미만) 자동으로 확인하고, 통과해야 분석할 수 있습니다.
- 입력은 **국내 생산물에 대한 최종수요 증가**이며, 수입 완제품 구매는 포함하지 않습니다. 이번 버전은 양의 증가액만 지원합니다.

## 4. 단위

- 금액표의 일반 데이터 단위는 **백만원**입니다. (1,000백만원 = 10억원)
- 투입계수·유발계수는 단위 없는 비율입니다. 구성비 등 요약 행은 행 이름을 확인하세요.

## 5. 파일 구성

```
index.html   화면 구성
style.css    디자인
app.js       버튼 동작과 결과 표시
worker.js    별도 작업 공간에서 Python(Pyodide) 실행
model.py     엑셀 읽기, 검증, 산업연관 계산
data/        분류 수준별 엑셀 4개
.nojekyll    GitHub Pages가 정적 파일을 그대로 게시하도록 하는 설정
```

- 자료: 2023년 산업연관표 연장표 투입산출표(생산자가격)
- 공개 저장소이므로 개인정보나 공개 권한이 없는 자료는 올리지 않았습니다.
- 한계: 분석은 단일 연도(2023) 기준의 수요충격 분석이며, 양의 수요 증가만 다룹니다.
